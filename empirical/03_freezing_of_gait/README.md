# Freezing of gait: S05R01 event 28

Illustrative Supplementary Figure S19. `data/S05R01.txt` is from the [Daphnet Freezing of Gait dataset](https://archive.ics.uci.edu/dataset/245/daphnet+freezing+of+gait), CC BY 4.0. Cite Roggen, Plotnik and Hausdorff (2010), DOI 10.24432/C56K78. The file checksum is in `../FILE_SHA256.csv`.

Run `python scripts/run_example.py`, then `python scripts/plot_example.py`. The runner loads only S05R01, identifies its 28th contiguous annotation-2 interval, and applies the archived `fog_nndr_revised_v2.py` window calculation to an aligned segment around it. The segment starts on the original 0.5 s grid, preserving the full-record window endpoints. No complete collection scan is run. `results/` contains newly calculated window diagnostics, magnitude CSV and illustrative PDF/PNG; `reference_data/` holds the final handoff plotting table.

The source uses the three ankle accelerations in mg, a centered affine first-order fit, 3 s trailing windows at 0.5 s steps, relative ridge 0.003, shrinkage 0.04, M2/M3, no forced spectral stabilization and normalized L1 response support. Event onset is 1316.422 s and offset 1326.641 s. All 62 overlapping endpoints per method reproduce the archived R_A values within 1e-13.

**Aggregation resolved:** Section S16 uses all admissible 0.5 s endpoints in the 15 seconds before onset (30 per method) and the full annotated interval (21 per method). The fresh `results/manuscript_event_summary.csv` gives pre/within medians: M3 R_A 0.543/1.370 and R_sigma 0.755/1.694; M2 R_A 0.579/1.368 and R_sigma 0.801/1.710. These reproduce the manuscript's rounded 0.54/1.37, 0.76/1.69, 0.58/1.37 and 0.80/1.71 values. The archived `all_event_contrasts_pilot.csv` uses an eight-window matched baseline and only the first four seconds after onset, giving M3 R_A 0.245/1.950 and M2 0.263/1.950. Both are valid summaries of different endpoint sets. No fit parameter, gate or individual window value was changed. This event was selected after inspection and is illustrative; other events are heterogeneous, including the S20 example without the same increase.
