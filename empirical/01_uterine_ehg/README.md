# Uterine EHG: ice039_p_3of6

Representative Figure 9(a,c) and Supplementary Figure S11. The PhysioNet [Icelandic 16-electrode EHG database v1.0.0](https://physionet.org/content/ehgdb/1.0.0/) supplies the `.dat`, `.hea` and `.atr` files in `data/` under the Open Data Commons Attribution License 1.0. Cite Alexandersson et al., *Scientific Data* **2**, 150017 (2015), DOI 10.1038/sdata.2015.17, and PhysioNet. Exact local checksums are in `../FILE_SHA256.csv`.

Install the root requirements, then run `python scripts/run_example.py` followed by `python scripts/plot_example.py` from this folder. The wrapper invokes the archived `ehg_final_v2_full_cohort.py` for **one** recording with `representative=False`, which selects all 16 EHG channels. It does not enter the script's cohort mode. Results are written under `results/`; the archived `reference_data/` files are read only.

The source retains the 0.08–2 Hz filter, mV-to-µV conversion, 10 Hz resampling, mean analytic-envelope activity, 60 s trailing windows at 5 s steps, relative ridge 0.003, shrinkage 0.10, M2/M3, stability and real-log gates. `windows.csv` contains both ratios, normalized L1 response support, one-step multiplier splitting `Delta`, statuses and reduced matrices. `activity_envelope.csv`, `detected_activity_peaks.csv` and `meanfield_reconstruction.csv` provide the additional series. `ehg_example.pdf` and PNG are illustrative plots.

There are 679 endpoints and eight detected activity peaks. The minimum finite R_A is 1.5645 (M2) and 1.5659 (M3). Against the archived cache, M2 R_A differs by at most 1.5e-7 and M3 by 4.8e-6. M3 R_sigma differs by at most 7.2e-5. The M3 response-support maximum difference is 0.0747 in 100 windows, associated with a different direction choice within the same well-separated commutator plane; the ratios and one-step splitting remain close. These direction-dependent values should not be declared identical to the archived support series. See `EHG_DIRECTION_AUDIT.md` for the source-level diagnosis.
