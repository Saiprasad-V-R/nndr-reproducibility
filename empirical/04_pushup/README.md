# Rhythmic push-up motion

Supplementary Figure S21. The raw Apple Watch recording is `data/raw_samples_Pushup_duo_27Dec2025..csv` (checksum in `../FILE_SHA256.csv`). Didier, the original recording owner, authorized its publication. No specific data license has been assigned; see `../DATA_LICENSES.md`.

Run `python scripts/pushup_subset_final_5s_bootstrap.py`, `python scripts/run_timing_example.py`, then `python scripts/plot_example.py`. The subset script imports the archived final fit implementation and recomputes the primary low/high activity analysis from the raw samples. It uses 5 s circular blocks and 2,000 bootstrap replicates. The timing runner uses the same raw activity envelope, global response directions and 1,000 circular shifts with a minimum 3 s shift. `results/` contains the newly calculated tables, correlations and illustrative PDF/PNG. `reference_data/` contains the archived reference results.

The primary analysis uses three-axis gravity-removed user acceleration, residual channel demeaning, a causal preceding-0.5-s activity envelope, upper-15% high-activity class, first-sample pair labels, relative ridge 0.003, trace-preserving shrinkage 0.04 and separate M2/M3 fits without forced stabilization. It reproduces 1,913 low and 338 high adjacent pairs. Raw-data point estimates match the archived table to within 6e-14: M2 R_A 0.248/0.460 and R_sigma 0.343/0.678; M3 R_A 0.010/0.474 and R_sigma 0.014/0.699. The observed activity-response correlations are 0.313 (M2) and 0.321 (M3), with upper-tail shift p=0.000999 for each.

`fig15_pushup_revised_final.py` is retained from the latest revision for its phase-adaptive cycle-removal and broader control workflow; its internal exploratory bootstrap defaults (300 replicates, 1 s blocks) differ from the 2,000-replicate primary subset script and must not be substituted for it. `pushup_registered_tvnormal_null.py` and archived `observed_windows.csv` retain the separate 1 s/0.1 s moving-window normal-reference control; it was not rerun here. This one-recording result does not establish a general biomechanical mechanism.
