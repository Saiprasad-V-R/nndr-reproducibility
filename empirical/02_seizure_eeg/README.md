# Seizure EEG: chb01_03

Representative Figure 9(b,d), using only `chb01_03.edf`. The file comes from [CHB-MIT Scalp EEG Database v1.0.0](https://physionet.org/content/chbmit/1.0.0/), licensed under Open Data Commons Attribution 1.0. Cite Shoeb, *Application of Machine Learning to Epileptic Seizure Onset Detection and Treatment*, MIT (2009), and PhysioNet. Its local SHA-256 is in `../FILE_SHA256.csv`. The [official annotation](https://physionet.org/content/chbmit/1.0.0/chb01/chb01-summary.txt) gives onset 2996 s and offset 3036 s.

Run `python scripts/run_example.py`, then `python scripts/plot_example.py`. The runner calls the validated single-EDF evaluator and its original Stage-6 calculation helper. `eeg_geometry.py` contains the exact entropy-support and multiplier-splitting functions extracted from the corrected geometry source. No cohort main routine is called. `results/window_diagnostics.csv` is recomputed from the EDF, while `reference_data/` remains untouched.

The 16 bipolar channels retain the source order, 0.5–15 Hz bandpass, 60 Hz notch, 256-to-32 Hz resampling, original centering, 40 s trailing windows at 2 s steps, relative ridge 0.003, shrinkage 0.05, M2/M3 and stability/principal-log gates. Support is the entropy measure exp[-Σp log p]/16, not L1 support. The CSV includes R_A, R_sigma, support, one-step multiplier splitting and admissibility. The plot shows the mean field and annotated seizure. Its R_A and R_sigma panels use 0–3 linear display limits, following the narrow-range convention of the clean manuscript Figure S15. Five in-view R_sigma values above 3 are marked at the upper boundary; the CSV retains their exact values, and the annotation is a display cue rather than a numerical cap.

All 201 endpoints match the archived time grid. Maximum differences versus the archived raw columns are 2.0e-8 for M2 R_A, 2.6e-12 for M3 R_A, 6.9e-7 for M2 R_sigma and 4.1e-12 for M3 R_sigma; support differs by at most 1.3e-7. For the -100 to 0 s endpoint window, median R_A is 0.961 (M2) and 0.922 (M3); for 0 to <40 s it is 1.367 (M2) and 1.375 (M3). These are close to the task's rounded 0.95/0.92 and 1.37/1.38 anchors; the exact manuscript selection rule was not independently recoverable from the clean PDF in this workspace.
